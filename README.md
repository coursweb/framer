# Utilisation de Framer

Ce support documente Framer, une application de webdesign.

## Extensions et utilitaires

Pour exporter un design depuis Figma dans Framer, l'extension officielle: 

* **[Figma to HTML with Framer](https://www.figma.com/community/plugin/1037108608720448600/figma-to-html-with-framer)** : cette extension Figma permet de copier-coller des designs depuis Figma vers Framer.

Pour copier coller des éléments d'un site web vers Framer:

* **[HTML to Framer](https://chromewebstore.google.com/detail/html-to-framer/haijifigpgpndcnbbjooffflaceedhdp)** : extension pour le navigateur Chrome.
